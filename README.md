# Shared with work

## Umbraco MCP with Copilot Enterprise agents

A discussion draft (9 October 2026) on how AI assistants could help TPR's content managers with everyday work on our Umbraco sites: content audits, finding pages that need updating, accessibility checks and first drafts. Everything happens within each editor's existing permissions, and a person reviews every change before it's published.

**[Read the PDF](Umbraco-MCP-Copilot-Agents-TPR.pdf)**

## Teams message for the content management team

> Hi all 👋
>
> I've put together a short discussion draft on something I think could save us a lot of time: using AI assistants to help with content work in Umbraco.
>
> Umbraco now has an official way for an AI assistant to work with our sites safely. In practice, you could ask in plain English for things like:
>
> • "List every page under Guidance with a missing or overlong summary"
> • "Find all pages that mention the old scheme return deadline"
> • "Which pages in this section haven't been updated for over a year?"
> • "Find images with missing alt text"
> • "Draft a new guidance page from these notes, but don't publish it"
>
> The assistant signs in as you, so it can only see and change what you already can. It saves drafts rather than publishing, and every change shows in the audit history under your name.
>
> Nothing changes yet. I'm proposing a small, time-boxed pilot on a test site first, with information governance and security sign-off before anything wider.
>
> Part A (the first two pages) is written for content managers. The rest is the technical detail for developers. I'd love to hear what you think, especially which tasks would help you most:
> https://github.com/AlexBeesley/shared-with-work/blob/main/Umbraco-MCP-Copilot-Agents-TPR.pdf
>
> Thanks!
> Alex
